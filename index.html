Personal research tool

Private ephemeris archiving.

Starlink ITC Azure Trial collects publicly available Modified ITC satellite ephemeris files and saves research copies in the owner's private Google Drive.

The collector runs on the owner's Azure server. It preserves source version names, extracts state vectors, compresses files, checks uploaded file metadata, and records collection status. The project name retains “Trial” from its initial deployment; collection may continue while the owner keeps it enabled.

Why it requests Google Drive access

The desktop authorization flow requests only https://www.googleapis.com/auth/drive.file. This permits access to files the app creates or files the user explicitly makes available to the app. The collector uses this access to create its private archive folders, upload ephemeris files and status records, and verify file sizes and checksums. It may check the authorized account and remaining storage to confirm the destination is usable.

This website provides application information. It has no Google sign-in form and does not display private archives or credentials. Authorization is completed on Google's own consent page.

Owner and availability

Maintained by hatttdemo-pixel for personal research. This is not a public collection service. It is an independent project, unaffiliated with SpaceX, Starlink, Google, or Microsoft.

Read the privacy policy and terms of use before authorizing the tool.
