Privacy policy

This policy describes the personal research collector Starlink ITC Azure Trial, maintained by hatttdemo-pixel, and this public information website.

Google data accessed and purpose

The app requests the drive.file OAuth scope. It accesses app-created files and folders, or files the user explicitly makes available to it. It uses file names, IDs, folder relationships, sizes, checksums, and app properties to create and verify private ephemeris archives, status reports, and completion indexes. Account email, account permission ID, and storage quota may be checked to verify the archive destination and available space.

The app does not request unrestricted Drive access. It does not request Gmail, contacts, calendar, or Google account password access.

Storage and processing

Public source ephemeris files are downloaded and processed on the owner's Azure server. Collection queues, file metadata, status records, and bounded recovery copies are stored there. Archive files and status records are uploaded to the authorized owner's private Google Drive folders.

OAuth client credentials and access/refresh tokens are stored in access-restricted files on the owner's computer and server. Tokens are sent to Google's authentication and API endpoints as required to perform authorized operations. Credentials are not included in public site files or archive reports.

Sharing and limited use

The app does not publish the owner's Drive files or change them to public sharing. Google user data is used only to provide and maintain the described archiving function. It is not sold, used for advertising, or used to train general-purpose AI or machine-learning models. Processing uses the owner's Azure server and Google's authentication and Drive services; no separate public data feed is provided.

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation, and deletion

The owner retains research archives and audit records until they choose to delete them. Temporary download files are removed after verified archiving; some compressed outputs and recovery copies remain on the server under storage limits. The owner can stop the collector, delete its local credentials and stored records, and delete archive files through Google Drive.

Google access can be revoked through Google Account connections. Revocation prevents future authorized API operations; it does not automatically delete existing Drive archives or server records. Reauthorization may be required after revocation or token expiry.

This information website

The website has no application login, analytics scripts, advertising, or application cookies. When hosted on GitHub Pages, GitHub processes website request metadata, including IP addresses, for hosting and security under the GitHub Privacy Statement.

Contact and updates

The maintainer's public profile is github.com/hatttdemo-pixel. The account owner manages their own server and archive. Material changes to data practices will be reflected in this page before the changed behavior is enabled.
